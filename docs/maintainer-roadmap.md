## Growth through usefulness

Share an honest before/after demo: show an audit without an API key, expand one check, export the report. Invite users to report a reproducible extraction failure. Prioritize fixes from real sites and contributors over unsupported feature-count claims. Stars are voluntary; this plan does not promise a number of stars.
