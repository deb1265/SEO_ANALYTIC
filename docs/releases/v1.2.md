# SEO Analytic Studio v1.2

A professional SEO consulting workspace with evidence-based audits, sourced strategy and client-ready reports.

## Highlights

- **Muse Spark 1.3 strategy:** competitor research, keyword intent and page mapping, content briefs, suggested copy and a 30/60/90-day plan.
- **Client reports:** saved reports, business branding, consultant notes, report fees and draft/reviewed/delivered status.
- **Charts and progress:** page-check results, body-term counts, task completion and recorded keyword positions.
- **PDF and JSON export:** branded, paginated PDFs with embedded fonts and measured charts.
- **Bounded site sampling:** up to five public HTML pages, robots/sitemap checks and authorized HTML import when access is blocked.
- **Patriot case study:** four audited pages, four competitors, 15 keyword opportunities, 12 prioritized recommendations and five content briefs.

## Reliability and security

- Repairs the original build and retains the free, no-key HTML checker.
- Replaces unsupported ranking and performance estimates with transparent HTML checks and explicit unmeasured states.
- Keeps production OpenRouter credentials on the server, outside source and browser bundles.
- Saves reports in owner-scoped D1 records with revision conflict protection.
- Fixes sidebar actions on short and mobile screens.
- Preserves the separate Vercel free-checker build.

## Getting started

Requires Node.js 24+. Run `npm ci`, then `npm run dev`. See the README for server-side AI configuration and deployment details.

The hosted reporting workspace is private to its owner. Client delivery is available through exported PDFs. Report fees are recorded; online payment collection is not connected. Search rankings, search volume, traffic and Core Web Vitals require measured data and are not generated by AI.

## Validation

The release workflow runs the production build, 20 extraction/interface tests, 6 API/storage/security tests and 3 browser tests before publication.
